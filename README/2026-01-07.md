2.目标: 用自己的 demo 项目，通过 yarn link 把 React 源码包链接过去

1）先在 React 仓库里构建出可被 link 的产物
还是在 React 仓库根目录：

sudo n
选择  16.x版本的node

如果报没java环境  参考`2025-12-31.md`

yarn build

如果只是测试这2个包，直接运行下面代码，速度更快
yarn build react/index,react-dom/index,scheduler --type=NODE

使用--type=NODE  是为了让包可以被其他项目使用，使用UMD导出的好像不能使用；
不加 scheduler 会报错

构建成功后，一般会在类似路径生成产物（不同版本路径不同）：
build/node_modules/react
build/node_modules/react-dom

你可以用下面命令确认有没有 build 出来：
ls build/node_modules | head

2）在 React 仓库里把包 link 出去
在 React 仓库根目录执行（如果不行就按下面“进入具体包目录”的方式）：
cd build/node_modules/react
yarn link
cd ../react-dom
yarn link

3）在你的 demo 项目里接入 link

创建demo项目:
  npx create-react-app a-react-demo
  cd a-react-demo
进入你的 demo 项目：
yarn link react
yarn link react-dom

然后启动你的 demo：
yarn dev
或
yarn start

4）修改源码并重新构建（重要！）
⚠️ 重要：必须修改源码，而不是修改构建产物！

修改源码的正确位置：
- React 核心代码：`packages/react/src/React.js`
- React Hooks：`packages/react/src/ReactHooks.js`
- React DOM：`packages/react-dom/src/ReactDOM.js`
- 其他文件：`packages/react/src/` 或 `packages/react-dom/src/` 目录下

修改后，在 React 仓库根目录重新构建：
yarn build react/index,react-dom/index,scheduler --type=NODE

构建会自动清理旧的 build 目录，所以不需要手动删除。

⚠️ 常见问题：修改了代码但浏览器没看到效果？

1. 确认修改的是源码（packages/react/src/），不是构建产物（build/node_modules/react）
2. 确认重新运行了构建命令
3. 确认 demo 项目使用的是开发模式（NODE_ENV !== 'production'）
   - create-react-app 默认是开发模式，应该没问题
   - 如果使用生产模式，会加载 react.production.min.js，看不到 console.log
4. 清除 demo 项目的缓存：
   - 删除 node_modules/.cache（如果存在）
   - 重启开发服务器
   - 硬刷新浏览器（Cmd+Shift+R 或 Ctrl+Shift+R）

测试代码示例（已添加到 React.js）：
```javascript
// 在 packages/react/src/React.js 文件开头添加
if (typeof console !== 'undefined') {
  console.log('🚀 React 源码已加载！这是从源码构建的版本');
}
```

5）避免 "Invalid hook call / 两份 React" 问题（非常常见）
如果你遇到 Invalid hook call，99% 是因为项目里同时存在两份 React（一个来自 link，一个来自依赖树）。

处理思路（给你最常用的两种）：

方式 1：锁定只用 link 的那份
确认 yarn why react 看看是不是还有别的 react 来源
确保你的 demo 项目的 node_modules 里没有另外装一份不同路径的 react（必要时删 node_modules 重装）

方式 2：用 resolutions 强制依赖收敛（yarn classic 常用）
在 demo 的 package.json 加：
{
  "resolutions": {
    "react": "link:react",
    "react-dom": "link:react-dom"
  }
}
然后：
rm -rf node_modules
yarn

2）Chrome DevTools 断点方式（最简单）
浏览器打开你的 demo 页面
DevTools → Sources
Ctrl/Cmd + P 搜索关键词，比如：
   - beginWork
   - commitRoot
   - performUnitOfWork
   - dispatchSetState / dispatchActionState（具体函数名随版本）
在函数入口打断点
页面里触发一次更新（点击按钮 setState），观察调用栈

3）VSCode 断点方式（更顺手）
如果你用 Vite/webpack dev server 跑 demo，推荐用 JavaScript Debug Terminal：
VSCode → Terminal → JavaScript Debug Terminal
在这个终端里启动你的 demo：yarn dev
VSCode 里直接打开映射出来的源码文件打断点
触发更新即可停住
