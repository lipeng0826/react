A. 在仓库内跑官方 demo（fixtures）：最快验证“能进源码”

1）安装 & 基础检查
仓库根目录
node -v
yarn -v

yarn

2）构建（带 sourcemap 的开发构建）
React 仓库常用的是 yarn build 或 yarn build react/index,react-dom/index（不同版本脚本略有差异）。

先直接试：
yarn build

报错，是没有rollup，然后切到20版本的node，感觉这个node太新了

npm i -g npm
sudo n 16
n 16
node -v

报错，没有jdk

brew install openjdk@17
苹果芯片：
export PATH="/opt/homebrew/opt/openjdk@17/bin:$PATH"
java -version
intel
export PATH="/usr/local/opt/openjdk@17/bin:$PATH"

执行：yarn build-combined --type=UMD  生成更加全的内容

如果构建很慢/想只构建核心包，试类似（看你仓库 scripts 支持什么）：
yarn build react/index,react-dom/index --type=NODE
或
yarn build react/index,react-dom/index --type=DEV

构建核心包的话其他包会丢失，不行；

3）运行 fixtures
一般 fixtures 在：
cd  fixtures/dom

npm run start
