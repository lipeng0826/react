## 5. 快速开始调试（第一次调试必看）

### 步骤1：验证环境是否正常

1. **确认 demo 项目已启动**

```sh
# 在 demo 项目目录
yarn start
```

   打开浏览器访问 `http://localhost:3000`

2. **检查控制台是否有测试日志**
   打开浏览器 DevTools Console，应该能看到：

   ```
   🚀 React 源码已加载！这是从源码构建的版本
   ```

   如果看到这个日志，说明环境搭建成功！

### 步骤2：第一次调试 - 调试 useState

**目标：** 追踪 `useState` 的调用流程

**1. 在 demo 项目中创建一个测试组件**

在 `src/App.js` 中添加：

```javascript
import { useState } from 'react';

function App() {
  const [count, setCount] = useState(0);
  
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  );
}

export default App;
```

**2. 在源码中添加调试代码**

编辑 `packages/react/src/ReactHooks.js`，找到 `useState` 函数（约第80行）：

```javascript
export function useState<S>(
  initialState: (() => S) | S,
): [S, Dispatch<BasicStateAction<S>>] {
  console.log('🔍 useState 被调用，初始值:', initialState);
  const dispatcher = resolveDispatcher();
  return dispatcher.useState(initialState);
}
```

**3. 重新构建**

```bash
# 在 React 仓库根目录
yarn build react/index,react/jsx-runtime,react/jsx-dev-runtime,react-dom/index,scheduler --type=NODE_DEV
```

**4. 清除缓存并刷新**

```bash
# 在 demo 项目目录
rm -rf node_modules/.cache
# 然后刷新浏览器（Cmd+Shift+R 或 Ctrl+Shift+R）
```

**5. 查看效果**

- 打开浏览器 Console
- 刷新页面，应该能看到 `useState 被调用` 的日志
- 点击按钮，应该能看到 `useState` 再次被调用的日志

### 步骤3：使用 debugger 断点调试

编辑 `packages/react/src/ReactHooks.js`：

**2. 重新构建并刷新**

**3. 打开 DevTools**

- 确保 DevTools 是打开状态
- 刷新页面
- 代码会在 `debugger` 处暂停
- 可以查看变量值、调用栈等

**4. 调试技巧**

- 使用 **F10** 单步跳过（Step Over）
- 使用 **F11** 单步进入（Step Into）
- 使用 **F8** 继续执行（Resume）
- 在 **Call Stack** 面板查看调用链
- 在 **Scope** 面板查看变量值

### 步骤4：追踪 setState 调用链

**目标：** 追踪点击按钮后，`setCount` 如何触发更新

**1. 在 demo 中添加更多日志**

在 `App.js` 中：


### 调试工作流总结

每次修改源码后的标准流程：

```bash
# 1. 修改源码（packages/react/src/ 或 packages/react-dom/src/）
# 2. 在 React 仓库根目录重新构建
yarn build react/index,react/jsx-runtime,react/jsx-dev-runtime,react-dom/index,scheduler --type=NODE_DEV

# 3. 在 demo 项目目录清除缓存
```

**💡 提示：** 如果修改后没看到效果，99% 是因为：

2. 忘记清除缓存
3. 忘记硬刷新浏览器

## 6. 无 SourceMap 调试方法（推荐）

由于没有 sourcemap，调试需要一些技巧。以下是几种实用的方法：

### 方法1：在源码中添加调试代码（最推荐）

**优点：** 代码清晰，易于维护，可以添加详细的日志

**步骤：**

1. 在源码中添加 `debugger` 或 `console.log`

   ```javascript
   // 例如：packages/react-reconciler/src/ReactFiberWorkLoop.old.js
   function beginWork(current, workInProgress, renderLanes) {
     debugger; // 浏览器会自动停在这里
     console.log('🔍 beginWork:', {
       tag: workInProgress.tag,
       type: workInProgress.type,
       key: workInProgress.key
     });
     // ... 原有代码
   }
   ```

2. 重新构建：

   ```bash
   yarn build react/index,react/jsx-runtime,react/jsx-dev-runtime,react-dom/index,scheduler --type=NODE_DEV
   ```

3. 清除缓存并重启 demo：

   ```bash
   # 在 demo 项目目录
   rm -rf node_modules/.cache
   yarn start
   ```

4. 打开浏览器 DevTools，触发操作，代码会在 `debugger` 处停止

**常用调试位置：**

- `packages/react-reconciler/src/ReactFiberWorkLoop.old.js` - `beginWork`, `completeUnitOfWork`
- `packages/react-reconciler/src/ReactFiberCommitWork.old.js` - `commitRoot`, `commitMutationEffects`
- `packages/react/src/ReactHooks.js` - `useState`, `useEffect` 等 hooks
- `packages/react-dom/src/ReactDOM.js` - `render`, `hydrate`

### 方法2：Chrome DevTools 搜索函数（快速定位）

**优点：** 不需要重新构建，快速找到函数位置

**步骤：**

1. 打开 demo 页面，打开 Chrome DevTools
2. 切换到 **Sources** 面板
3. 按 `Ctrl/Cmd + P` 打开文件搜索
4. 搜索函数名或文件名：
   - `beginWork` - 开始处理一个 fiber 节点
   - `commitRoot` - 提交根节点
   - `performUnitOfWork` - 执行一个工作单元
   - `dispatchSetState` / `dispatchAction` - useState 的 dispatch
   - `scheduleUpdateOnFiber` - 调度更新
   - `react-dom.development.js` - 直接搜索文件

5. 在函数入口处打断点
6. 触发操作（点击按钮、setState 等）
7. 观察调用栈（Call Stack）了解执行流程

**技巧：**

- 使用 `Ctrl/Cmd + Shift + F` 在所有文件中搜索关键词
- 在 Call Stack 中点击不同层级，查看不同函数的上下文
- 使用 `Watch` 面板监控变量值

### 方法3：使用 console.log 追踪执行流程

**优点：** 不需要打断点，可以看到完整的执行流程

**在源码中添加日志：**

```javascript
// packages/react-reconciler/src/ReactFiberWorkLoop.old.js
function workLoopSync() {
  console.log('🔄 workLoopSync 开始');
  while (workInProgress !== null) {
    console.log('📦 处理 fiber:', workInProgress.type);
    performUnitOfWork(workInProgress);
  }
  console.log('✅ workLoopSync 结束');
}
```

**使用 Chrome DevTools 的 Console 过滤：**

- 使用 `console.log` 的样式：`console.log('%c 文本', 'color: red; font-size: 20px')`
- 使用 `console.group` 分组：

  ```javascript
  console.group('🔍 beginWork');
  console.log('current:', current);
  console.log('workInProgress:', workInProgress);
  console.groupEnd();
  ```

### 方法4：使用 React DevTools Profiler

**优点：** 可视化组件渲染性能，不需要修改代码

**步骤：**

1. 安装 React DevTools 浏览器扩展
2. 打开 DevTools，切换到 **Profiler** 标签
3. 点击录制按钮
4. 在页面上执行操作
5. 停止录制，查看火焰图
6. 点击某个组件，查看渲染时间和原因

### 方法5：在构建文件中直接调试（临时方案）

**⚠️ 注意：** 这种方法不推荐，因为重新构建会丢失修改

**步骤：**

1. 找到构建后的文件：
   - `build/node_modules/react-dom/cjs/react-dom.development.js`
   - `build/node_modules/react/cjs/react.development.js`

2. 直接搜索函数名（使用编辑器或 grep）

   ```bash
   grep -n "function beginWork" build/node_modules/react-dom/cjs/react-dom.development.js
   ```

3. 在函数中添加 `debugger` 或 `console.log`
4. 刷新浏览器即可生效（无需重启服务器）

### 方法6：使用 VSCode 调试（需要配置）

**配置 `.vscode/launch.json`：**

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "chrome",
      "request": "launch",
      "name": "Debug React Demo",
      "url": "http://localhost:3000",
      "webRoot": "${workspaceFolder}/../reactSource/demo1/a-react-demo",
      "sourceMaps": false,
      "skipFiles": ["<node_internals>/**"]
    }
  ]
}
```

**限制：** 由于没有 sourcemap，VSCode 无法直接映射到源码，但可以在构建后的文件中打断点。

### 调试技巧总结

1. **快速定位函数：** 使用 `Ctrl/Cmd + P` 搜索函数名
2. **查看调用栈：** 在 Call Stack 中点击不同层级
3. **监控变量：** 使用 Watch 面板或 Console 输入变量名
4. **条件断点：** 右键断点，设置条件（如 `workInProgress.tag === 1`）
5. **日志断点：** 右键断点，选择 "Add logpoint"，不暂停执行但输出日志
6. **性能分析：** 使用 Performance 面板录制，查看函数执行时间
